# AI Usage

Saya menggunakan AI sebagai alat bantu untuk belajar dan memahami materi HTTP, PHP, GET, POST, dan Form Handling.

AI membantu saya memahami:
- Perbedaan metode GET dan POST.
- Cara membuat form menggunakan HTML.
- Cara melakukan validasi data pada PHP.
- Penggunaan status HTTP seperti 405 dan 422.
- Struktur dan penataan CSS.

Saya tetap mempelajari dan memahami kode yang digunakan serta melakukan penyesuaian pada tugas saya.

AI digunakan sebagai alat bantu pembelajaran, bukan sebagai pengganti pemahaman saya dalam mengerjakan tugas.
